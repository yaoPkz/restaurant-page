# Waddle Dee Cafe

A themed restaurant homepage built with JavaScript, Webpack, and DOM manipulation.


## Features

- Home, Menu, and Contact tabs
- Dynamic page content created with JavaScript
- Navigation without page reloads
- Active navigation button styling
- Responsive restaurant layout
- Local image assets bundled with Webpack

## Built With

- HTML
- CSS
- JavaScript
- Webpack
- webpack-dev-server
- html-webpack-plugin
- css-loader
- style-loader
